# Настройки dsh-pet-cactus

## Где лежит

```
<DSH_HOME>/dsh-pet-cactus/main-config.json
```

`DSH_HOME` — переменная окружения, если задана; иначе `~/.dsh`.
Файл создаётся при первом сохранении из интерфейса или запросом `PUT /api/config`.

Правила:

- файла нет → работают умолчания, файл не создаётся сам;
- битый JSON → предупреждение в лог и умолчания; **файл не перезаписывается**;
- неизвестные ключи игнорируются и перечисляются в ответе `PUT` (`rejected`);
- неверный тип или выход за диапазон → `400 invalid-config`, ничего не пишется;
- запись атомарная: временный файл + `rename`, читатель не увидит половину JSON.

## Ключи

| Ключ | Тип | По умолчанию | Границы | Что значит |
|---|---|---|---|---|
| `name` | строка | `"Кактус"` | 1–40 символов | имя для `aria-label` |
| `size` | число | `240` | 120–420 | ширина, px; высота = ширина × 1,25 |
| `corner` | строка | `"bottom-right"` | `top-left`, `top-right`, `bottom-left`, `bottom-right` | угол, пока позиция не перетащена |
| `marginX` | число | `28` | 0–200 | отступ от края по горизонтали, px |
| `marginY` | число | `28` | 0–200 | отступ от края по вертикали, px |
| `opacity` | число | `1` | 0.3–1 | прозрачность |
| `speech` | bool | `true` | — | говорить сам с собой |
| `speechIntervalMin` | число | `12` | 1–180 | средний интервал реплик, минуты (±30 % случайности) |
| `bubbleMs` | число | `6500` | 2000–30000 | сколько висит пузырь, мс |
| `sleepAfterMin` | число | `20` | 1–240 | через сколько минут без действий засыпать |
| `reactToAgent` | bool | `true` | — | реагировать на события сессий |
| `reducedMotion` | строка | `"auto"` | `auto`, `reduce`, `allow` | `auto` уважает системную настройку, `reduce` гасит анимации, `allow` включает всегда |
| `phrases` | массив строк | `[]` | ≤ 30 строк, ≤ 140 символов | свои фразы; добавляются в пул покоя |

Перетаскивание сохраняет позицию в `localStorage` браузера (ключ
`dsh-pet-cactus:position`) и перекрывает `corner`/`marginX`/`marginY`.
Меню у кактуса нет: сохранённую позицию стирают удалением этого ключа.

## Рецепты

**Тихий кактус в углу, не отвлекает**

```json
{
  "size": 180,
  "speech": false,
  "reactToAgent": false,
  "opacity": 0.9,
  "marginX": 16,
  "marginY": 16
}
```

**Большой и разговорчивый**

```json
{
  "size": 360,
  "speech": true,
  "speechIntervalMin": 4,
  "bubbleMs": 9000
}
```

**Только в левом верхнем углу, без перетаскивания**

Удалить сохранённую позицию (ключ `dsh-pet-cactus:position` в localStorage:
DevTools → Application → Local Storage) и задать:

```json
{ "corner": "top-left", "marginX": 40, "marginY": 40 }
```

**Свои фразы**

```json
{
  "phrases": [
    "Не забудь про перерыв.",
    "Ещё один коммит — и спать.",
    "Я в тебя верю, колючий ты мой."
  ]
}
```

## Через HTTP

```sh
# прочитать всё
curl http://127.0.0.1:<порт>/dsh-pet-cactus/api/config

# изменить два ключа
curl -X PUT http://127.0.0.1:<порт>/dsh-pet-cactus/api/config \
  -H 'content-type: application/json' \
  -d '{"size": 300, "speech": false}'
```

Ответ на успех:

```json
{ "config": { "...": "..." }, "path": "...", "rejected": [] }
```

Ответ на ошибку (`400`):

```json
{ "error": "invalid-config", "details": ["size: ожидалось число в диапазоне 120..420"] }
```

Изменения из файла подхватываются **после перезапуска DSH**: конфиг читается
один раз при загрузке плагина. `PUT` обновляет кеш хоста сразу и отвечает новым
конфигом; открытое окно применит его при следующей загрузке страницы.
